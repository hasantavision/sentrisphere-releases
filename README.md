# SentriSphere appliance releases

This repository is the public download location for versioned SentriSphere
appliance installers, model artifacts and release records. Application
development remains in its separately managed source repository.

Each published appliance release includes its installation script, immutable
image references, source revision, board compatibility profile and artifact
SHA-256 checksums. Installation prepares the application; owners register and
configure their cameras in the browser afterward.

The first RK3576 online installer is being prepared. No customer installation
command is available until its release assets and acceptance record are
published. Download commands will be listed on the corresponding release page.

Hardware initialization checks and edition camera limits do not establish
detector accuracy or sustained camera capacity. Consult each release's tested
configuration and qualification record.
